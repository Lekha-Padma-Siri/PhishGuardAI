# PhishGuardAI

PhishGuard is a cybersecurity prototype that checks suspicious messages for common phishing signals.

## What it does

**Paste Message → Analyze → Show Risk → Explain Signals → Give Safety Tip**

It checks for:

* Urgent/pressure words
* Account verification requests
* Password/OTP requests
* Suspicious links
* Threats or warnings
* URLs

## Tech Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download the project.
2. Open the `prototype` folder.
3. Double-click `index.html`.
4. Paste a suspicious message.
5. Click **Analyze Message**.

No installation or API key is required.

## Limitations

This is a prototype and not a guaranteed phishing detector. It may miss some phishing messages or incorrectly flag normal messages.

It does not access email, WhatsApp, SMS, or private accounts.

**Do not enter passwords, OTPs, card details, or other sensitive information.**
